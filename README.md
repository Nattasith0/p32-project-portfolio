# P32 — Project & Portfolio

ระบบบริหารและติดตามโครงงานนักศึกษา พร้อมแฟ้มสะสมผลงานดิจิทัล
โครงงานกลุ่ม **P3.2** สาขาวิศวกรรมซอฟต์แวร์

> **ชุดเผยแพร่รอบนี้: พื้นฐานระบบและบัญชี/สิทธิ์ผู้ใช้ (ระยะ 1–2)**
>
> โค้ดชุดนี้เลือกจาก checkpoint ที่พัฒนาไว้จริง เพื่อให้ติดตั้งและทดสอบร่วมกันได้ครบ
> ไม่ใช่ซอร์สล่าสุดทั้งหมดของโครงการ และยังไม่พร้อมส่งมอบระบบจริง

ข้อมูลชุดเผยแพร่ ณ **24 พฤศจิกายน 2569**

## ฟังก์ชันที่มีใน repository รอบนี้

| ส่วน | สิ่งที่ทดลองได้ |
| --- | --- |
| พื้นฐาน | Next.js + Express, API Health และการเชื่อม PostgreSQL |
| บัญชี | Login/Logout ด้วยบัญชีทดสอบ ตรวจข้อมูลและรหัสผ่าน Argon2id |
| Session | JWT ตรวจร่วมกับ active session, cookie, Origin/CSRF และการเพิกถอน session |
| สิทธิ์ผู้ใช้ | หลายบทบาท รายการบทบาท และการเพิ่ม/ถอนบทบาทพร้อมประวัติ |
| ผู้ดูแลระบบ | ค้นหาบัญชีและดูบทบาทของบัญชีที่เลือกผ่าน API และหน้าจอ |
| ฐานข้อมูล | Migrations 6 รายการและ seed บัญชีสมมติ admin/student |
| ส่วนติดต่อ | หน้า Login หน้าแรกหลังเข้าสู่ระบบ และหน้ารายการบทบาทสำหรับผู้ดูแล |
| การตรวจ | Unit/integration tests, TypeScript, lint และ production build |

บทบาททางวิชาการมีรหัสเตรียมไว้ แต่ขอบเขตโครงงาน/รายวิชาและกระบวนการทางวิชาการไม่ได้รวมอยู่ในชุดนี้
การยืนยันอีเมลของบัญชี seed เป็นข้อมูลสมมติสำหรับพัฒนา ไม่ใช่การส่งอีเมลจริง

## ยังไม่รวมในรอบนี้

การรับ IF01/IF02, รายงานความก้าวหน้า, ประกาศ/ปฏิทิน/เอกสารรายวิชา,
คำขอและงานสอบ, ตรวจเล่ม, Digital Portfolio, IF03 และการแจ้งเตือน
จะเพิ่มเป็นชุดงานภายหลัง ส่วน Login กลางและข้อมูลคู่ทีมจริงยังรอข้อตกลงร่วม
