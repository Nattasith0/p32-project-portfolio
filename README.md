## ภาพรวมระบบ

P32 รวมงานรายวิชาโครงงานตั้งแต่การส่งรายงานความก้าวหน้า ตรวจและรับรองเอกสาร
ยื่นคำขอและขั้นตอนสอบ ตรวจเล่ม ติดตามสถานะ และจัดแสดงผลงานใน Digital Portfolio

ผู้ใช้หลัก ได้แก่ นักศึกษา อาจารย์ที่ปรึกษา ผู้ดูแลรายวิชา กรรมการสอบ และผู้ดูแลระบบ
ส่วนการเปิด Portfolio ให้ผู้ชมอื่นยังรอข้อสรุปสถานะและสิทธิ์ผู้ชม

## ลำดับงานสำคัญ

1. นักศึกษาส่งรายงานให้ที่ปรึกษาตรวจ
2. ที่ปรึกษาส่งกลับแก้ไข หรือแนบ PDF ลงนามรับรองตรงรุ่น
3. ผู้ดูแลรายวิชาเห็นและตรวจต่อเมื่อมีผลรับรองและ PDF ฉบับรับรองของรายงานรุ่นล่าสุดแล้วเท่านั้น

## โครงสร้างโครงการ

```text
.
├── README.md
├── .gitignore
├── backend/
│   ├── src/
│   │   ├── config/
│   │   ├── database/
│   │   ├── middleware/
│   │   ├── modules/
│   │   └── security/
│   ├── migrations/
│   ├── scripts/
│   ├── test/
│   ├── assets/
│   └── examples/
├── frontend/
│   ├── src/
│   │   ├── app/
│   │   ├── api/
│   │   ├── components/
│   │   ├── types/
│   │   └── assets/
│   ├── public/
│   └── test/
└── docs/
    └── roadmap.md
```

| ส่วน | หน้าที่ |
| --- | --- |
| backend/src | API กฎการทำงาน การตรวจตัวตน และสิทธิ์ |
| backend/migrations | โครงสร้างและสิทธิ์ฐานข้อมูล |
| backend/scripts และ examples | เตรียมข้อมูลสมมติ ตรวจระบบ และตัวอย่างเชื่อมต่อ |
| backend/test | ตำแหน่งสำหรับชุดทดสอบ Backend |
| frontend/src | หน้าเว็บ ตัวเรียก API และองค์ประกอบ UI |
| frontend/public | รูป โลโก้ และทรัพยากรหน้าเว็บ |
| frontend/test | ตำแหน่งสำหรับชุดทดสอบ Frontend |
| docs | แผนงานและเอกสารประกอบ |

โมดูล Backend ที่เตรียมโครงไว้ตรงกับระบบในเครื่อง ได้แก่
auth, authorization, continuation, courses, exam-requests, exports, health, imports, portfolio, project-requests, reports, roles, special-cases, users.

## เทคโนโลยีของระบบในเครื่อง

- Frontend: Next.js, React และ TypeScript
- Backend: Node.js และ Express
- ฐานข้อมูล: PostgreSQL

โค้ดและชุดทดสอบมีการพัฒนาในเครื่องแล้ว แต่ยังไม่รวมในการเผยแพร่รอบนี้
คำสั่งติดตั้งและวิธีเปิดระบบจะเพิ่มเมื่ออัปโหลดซอร์สที่จำเป็นครบ
