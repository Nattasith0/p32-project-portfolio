บันทึกวันที่ 24 พฤศจิกายน 2569

โค้ด Backend และ Frontend เลือกจาก checkpoint d6a6b8d ของ repository พัฒนาในเครื่อง
ซึ่งอยู่ก่อนเพิ่มโมดูลรับข้อมูลและกระบวนการโครงงาน
ประวัติการเผยแพร่บน GitHub ต่อจาก commit โครงสร้าง 224507c โดยไม่ส่งประวัติการพัฒนาทั้งหมด

ไฟล์ implementation, migrations และ tests ใช้จาก checkpoint ดังกล่าว
เอกสารหน้าแรกและคู่มือสำหรับชุดเผยแพร่จัดใหม่ให้ตรงกับขอบเขตนี้
ไม่ได้อ้างว่าชุดนี้เป็นหน้าจอและฟังก์ชันล่าสุดทั้งหมดในเครื่องพัฒนา

## รวมในชุดนี้

- โครง Frontend/Backend และ Health API
- บัญชี รหัสผ่าน session และการตรวจตัวตน
- การตรวจบทบาทและ API/หน้าจัดการบัญชีและบทบาท
- Migrations บัญชี/บทบาท/session/audit จำนวน 6 รายการ
- Seed เฉพาะบัญชีสมมติ admin_demo และ student_demo
- ชุดทดสอบของส่วนข้างต้นและไฟล์ติดตั้งที่ใช้ร่วมกัน

## ไม่รวม

- ข้อมูลรับเข้า IF01/IF02 และการส่งออก IF03
- รายงานความก้าวหน้า เอกสารรายวิชา และปฏิทิน
- คำขอ สอบ แก้หลังสอบ และตรวจเล่ม
- Portfolio และสิทธิ์ผู้ชมผลงาน
- แจ้งเตือนในเว็บ/LINE/อีเมลของงานโครงงาน
- บัญชีจริง ข้อมูลส่วนบุคคลจริง กุญแจ รหัสผ่าน และไฟล์ตั้งค่าจริง

โฟลเดอร์ของงานระยะถัดไปบางส่วนอาจมี .gitkeep เพื่อแสดงโครงสร้างเท่านั้น

## สิ่งที่ควรรู้เมื่อทดลอง

Health API ยืนยันว่า API ตอบกลับ ไม่ได้ยืนยันว่าคู่ระบบหรือฐานข้อมูลพร้อม
การตรวจสิทธิ์ต้องทำที่ Backend; การแสดงหรือซ่อนลิงก์ไม่ใช่การให้สิทธิ์
บทบาท advisor/course_manager/examiner ที่อยู่ในตารางไม่ได้ทำให้มีข้อมูลโครงงานหรือการมอบหมายจริง

ไฟล์ frontend/next-env.d.ts ถูก Next.js สร้างใหม่ระหว่างตรวจ build เพื่ออ้างอิง route types มาตรฐานของ build
เป็นไฟล์ประกาศชนิดที่เครื่องมือสร้าง ไม่มีการปรับตรรกะของระบบจาก checkpoint
ปรับเฉพาะบรรทัดว่างท้าย frontend/test/roleChangeApi.test.js เพื่อผ่านการตรวจ whitespace และทดสอบซ้ำแล้ว
