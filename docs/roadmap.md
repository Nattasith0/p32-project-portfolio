# แผนพัฒนา P32 — ฉบับคร่าว ๆ

ภาพรวม ณ **24 พฤศจิกายน 2569** อ้างอิงแผนงานของระบบที่พัฒนาในเครื่อง
แผนนี้แสดงทั้งงานที่มีผลทดสอบแล้วและสิ่งที่ยังต้องทำ ไม่ใช่ตารางส่งมอบที่ยืนยันวันเสร็จ

| ระยะ | งานหลัก | สถานะ |
|---|---|---|
| 1 | พื้นฐานโครงการ | โครง Frontend/Backend/ฐานข้อมูลใช้งานได้ มี RTM ฉบับพัฒนาแล้ว รอทวนเอกสารออกแบบและผลตรวจรับ |
| 2 | บัญชีและสิทธิ์ผู้ใช้ | ระบบบัญชีทดสอบและการจัดการบทบาทผ่านบนเครื่องพัฒนา กฎสิทธิ์ตามขอบเขตผ่านในบทเรียน งานบัญชีจริงและตัวเชื่อม Login กลางรอข้อสรุปของทีมกลาง |
| 3 | รับข้อมูล IF01/IF02 | ผ่านครบสำหรับข้อมูลจำลอง ตั้งแต่ preview ยืนยัน ใบรับผล การรับรุ่นใหม่ และให้ IF02 ใช้รายวิชาจาก IF01 บน PostgreSQL ในเครื่อง รอคู่ทีมยืนยันสัญญาและทดสอบแพ็กจริง |
| 4 | ส่ง–ตรวจรายงานครบหนึ่งรอบ | ผ่านการทดสอบบนเบราว์เซอร์ครบทั้งสามบทบาท รวมข้อมูลความก้าวหน้าและ PDF ฉบับรับรอง |
| 5 | ข้อมูลรายวิชาและรายงานครบ 3 รอบ | ประกาศ ปฏิทิน เอกสาร และรายงานครบ 3 รอบผ่านการทดสอบบนเครื่องพัฒนา ลงกำหนด ENGSE212 ภาคเรียน 2/2569 ในฐานพัฒนาแล้ว รอรายละเอียดการปิดรับและกติกาล่าช้า |
| 6 | คำขอ ข้อมูลสอบ แก้ไข และตรวจเล่ม | FR06–FR12, FR13 ส่วนอนุมัติเข้าเล่ม และ FR14 ผ่านบนเครื่องพัฒนา เส้นทางรวมผ่าน HTTP ด้วยข้อมูลทดสอบ ส่วนตรวจรับฉบับสมบูรณ์รอข้อมูลรายวิชา |
| 7 | Digital Portfolio | จัดการผลงาน แนบ PDF และบันทึกตัวเลือกเปิดชมได้ การเปิดให้ผู้อื่นชมรอการยืนยันสถานะและสิทธิ์ผู้ชม |
| 8 | ส่งข้อมูล IF03 | สร้างแพ็กและทดสอบใบรับผลกับการส่งซ้ำบนเครื่องได้ รอยืนยันสัญญาและสิทธิ์กับ P1/P1P2 |
| 9 | Dashboard แจ้งเตือน ไฟล์ ประวัติ และรายงาน | Dashboard และแจ้งเตือนรายงานภายในเว็บพร้อมบนเครื่องพัฒนา ส่งออก XLSX, PDF และเปิดหน้าพิมพ์ตามสิทธิ์ได้ เพิ่มประวัติ Portfolio และ checksum สำหรับไฟล์ดาวน์โหลดแล้ว ส่วน LINE/อีเมลพักไว้ |
| 10 | ทดสอบรวม ติดตั้ง สำรอง–กู้คืน และส่งมอบ | กำลังพัฒนาและทดสอบในเครื่อง ผ่านการซ้อมรายงานและทดลองติดตั้งกับกู้คืนแล้ว สถานะโครงการยังส่งมอบไม่ได้จนกว่าจะเชื่อมและทดสอบกับคู่ทีมจริง รวมถึงผ่านเกณฑ์ตรวจรับ |

## สิ่งที่ทำต่อได้ในเครื่อง

- ทวนแบบระบบและประวัติ/สิทธิ์ไฟล์ให้ตรงกับโค้ดปัจจุบัน
- วัดประสิทธิภาพและทดสอบกับผู้ใช้ตัวแทน
- เตรียมกรณีทดสอบร่วม คู่มือ รายงาน และบทสาธิตส่วนที่ยังขาด

## เรื่องที่รอข้อมูล

- Login กลาง รหัสบุคคลร่วม และข้อตกลง IF01–IF03 จากคู่ทีม
- กติกาส่งช้า/ส่งแก้ช้า กำหนดสอบรายกลุ่ม และเงื่อนไขตรวจรับเล่มสมบูรณ์จากรายวิชา
- สิทธิ์ผู้ชม Portfolio และข้อสรุปเกณฑ์ตรวจรับที่ยังค้าง

การแจ้งเตือน LINE/อีเมลพักไว้ตามแผนเดิม
รายละเอียดการแบ่งงานติดตามใน Trello ส่วนซอร์สและเอกสารฉบับเต็มจะเพิ่มใน repository ภายหลัง
